Nhạc giờ được thêm trong trang admin (mục 4. Nhạc): dán link YouTube / link .mp3, hoặc tải file mp3 từ máy lên.

Nếu muốn, vẫn có thể bỏ file nhạc vào thư mục này, đặt tên 1.mp3, 2.mp3 ... 20.mp3 (tối đa 20 bài);
trang tự tìm và cho vào danh sách "Nhạc mp3".

Lưu ý bản quyền: phát nhạc có bản quyền khi livestream YouTube có thể bị Content ID chặn hoặc tắt tiếng.
Nên dùng nhạc miễn phí bản quyền (YouTube Audio Library, Pixabay Music...).
